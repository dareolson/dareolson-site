Grant Radar

A Python pipeline that pulls federal award data from USAspending.gov, scores each award by fit and by how soon its funding window closes, and renders a ranked outreach dashboard. It deliberately separates what the data shows from what it cannot show, and flags stale results.

Python · Public APIs · Data scoring · Scheduled automation

How I work

I use AI-assisted tooling heavily, and I keep the judgment human: I model the domain, decide what the system should refuse to do, and verify the result with unit, route-handler, and end-to-end tests that run against the deployed site. On the Rate Guide, one module is the single source of truth for market rates, and the API validates every input against it, so the guides, calculator, and job rules cannot drift apart.
