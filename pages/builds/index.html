How I work

I use AI-assisted tooling heavily and keep the judgment human: I model the domain, decide what the system should refuse to do, and verify the result with unit, route-handler, and end-to-end tests that run against the deployed site.

On the Rate Guide, one module is the single source of truth for market rates, and the API validates every input against it, so the guides, the calculator, and the job rules cannot drift apart.
